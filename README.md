# SAQ — Возражения

Тестовый модуль ДВГА с тремя исходными обращениями: на уведомление, аудиторский отчёт и акт профилактического контроля.

Сайт: https://saq-objections-test.vercel.app/

Репозиторий: https://github.com/ewgftju/ewgftju-saq-objections-test

## Структура как в проекте команды

Подход сопоставлен с `ewgftju/saq-prof-control-demo`, ветка `main`, снимок дерева `48b2426042aafc28753d1ad9cf8d3b62103774fa`.

- `frontend/` — React 19, TypeScript в strict-режиме, Vite 7.
- `frontend/src/components/` — общие элементы интерфейса и шапка SAQ.
- `frontend/src/modules/objections/` — модуль, страницы, формы, маршруты, модель и сервисы процесса.
- `frontend/src/api/objectionsRepository.ts` — изолированный адаптер хранения демо.
- `frontend/src/types.ts` — типы карточек, пунктов, ролей, решений и документов.
- `frontend/src/data/` — тестовые обращения и справочники.
- `frontend/src/modules/objections/tests/` — проверки предметной логики и React-разметки.
- `docs/` — нормативная модель, архитектура и сценарий показа.

Интерфейс сохранён в стиле `saq-prof-test`: палитра, шапка, боковая навигация, кнопки и карточки. Шрифт Roboto включён в сборку, без зависимости от внешнего сервиса шрифтов.

Это frontend-прототип. Django/DRF и PostgreSQL из референсного проекта сюда не скопированы: серверная часть и интеграции в этой версии не реализованы.

## Запуск и проверка

Нужен Node.js 20.19+ или 22.12+.

```sh
npm --prefix frontend ci
npm run dev
npm run typecheck
npm test
npm run build
```

В Windows при необходимости используйте `npm.cmd`.

## Основные маршруты

- `/cases` — реестр обращений.
- `/cases/:id/overview` — карточка.
- `/cases/:id/review` — рассмотрение по доводам.
- `/cases/:id/documents` — документы.
- `/cases/:id/history` — журнал действий.
- `/sessions` — заседания комиссии.
- `/processes` — бизнес-процессы.
- `/sources` — нормативная база и статус проверки.

Прямые ссылки работают через SPA-переадресацию в `vercel.json`.

## Границы демонстрации

Данные и вложения сохраняются в localStorage браузера; серверной авторизации нет. Роли переключаются в шапке. Все организации, БИН и обстоятельства вымышлены. ЭЦП, СЭД, портал закупок, аудиозапись и судебные системы имитируются. Максимальный файл — 2 МБ. Демо-календарь ограничен сентябрём–декабрём 2026 года.

Дата отправки результата и дата вручения фиксируются разными действиями. Печатные документы сохраняют снимок данных на момент формирования.

Полная проверка всех актуальных официальных редакций НПА ещё не завершена. Дополнительно сопоставлены доступные тексты изменений № 282 и № 523 за 2026 год. Маршрут профконтроля и утверждённые формы требуют согласования с ДВГА. Подробности — `docs/business-processes.md` и `docs/demo-readiness.md`.
